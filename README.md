# mac-apps

Jonas's Mac apps, one folder per app. Each folder has its own README with what
the app does and how to install or build it.

| Folder | App | Download |
| --- | --- | --- |
| [`Nib/`](Nib/) | Markdown editor, inspired by Lettera | [Nib 1.0.0](https://github.com/jonasspira/Nib/releases/tag/v1.0.0) |
| [`Tally/`](Tally/) | Notepad calculator, Soulver-style | [Tally 1.0.0](https://github.com/jonasspira/Tally/releases/tag/v1.0.0) |
| [`Pasties/`](Pasties/) | Menu bar clipboard queue | Build it yourself; see its README |
| [`OpenPops/`](OpenPops/) | Folders of apps, files and links in the Dock | [OpenPops 1.0.0](https://github.com/jonasspira/OpenPops/releases/tag/v1.0.0) |

Every app builds from the command line without an Xcode project. Apple's free
Command Line Tools are enough: `xcode-select --install`.

Each app used to have its own repository. Those are archived and read-only, and
they still hold the 1.0.0 downloads above. Newer releases appear on this
repository's [releases page](https://github.com/jonasspira/mac-apps/releases),
named after the app.

Web tools live in [jonasspira.github.io](https://github.com/jonasspira/jonasspira.github.io).
